## P1. Безопасность

| Пункт | Статус | Подтверждение |
|---|---|---|
| P1.1 SSRF в прокси медиа/видео/лент | **частично** | `lib/net-guard.mjs`: резолв DNS, блок приватных IPv4/IPv6, ручные редиректы ≤5, таймаут; применён в 8 точках (`serveImage`, `serveThumb`, `serveMedia`, `serveVideo`, `cachePostMedia`, `ensureCachedMedia`, `reachableImage`). **Осознанно не применён** к `httpGet`/`httpGetBinary` (загрузка лент) — иначе перестанут работать подписки на локальные адреса. Проверено: `127.0.0.1`, `169.254.169.254`, `2130706433`, `localhost` → 403, публичные картинки → 200 |
| P1.2 Path Traversal в `serveMedia()` | **сделано** | `mediaPathFor()` — шаблон `/^[A-Za-z0-9_-]{1,64}$/` + проверка `startsWith(root + sep)`; `?f=..&k=..` → 400 |
| P1.3 Обязательный текущий пароль | **сделано** | `if (!current \|\| !users.verify(...))` → 403; проверено: без пароля 403, с неверным 403, с верным 200 |
| P1.4 XSS-векторы | **сделано** | `entity.url` проверяется `/^(https?:|tg:)/i` + `escapeHtml`; `quoteAuthor` экранирован; `embedLink()` требует `^https?:`; `title` в подвале через `esc()`; инлайн `onerror` убран; `cssId()` = `CSS.escape` в 13 местах |
| P1.5 Аутентификация и секреты | **сделано** | `safeEqual` в `byApiKey`; `Secure` в cookie при HTTPS (проверено `set-cookie`); пароль админа не логируется; лимит 10 попыток в минуту на IP (11-я → 429) |
| P1.6 Личные данные в скриптах | **сделано** | `install-vps.sh` требует `DOMAIN` явно; в `publish.ps1` список адресов вынесен в локальный `tools/publish-leaks.txt` (в `.gitignore`); `cdp-traffic.mjs` по умолчанию ходит на `127.0.0.1:8787` или `RSS_TEST_URL` |
